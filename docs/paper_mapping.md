# Mapping from manuscript diagnostics to package components

| Manuscript quantity | Package function / routine |
|---|---|
| Relative L2 error | `diagnostic_suite.metrics.rel_l2` |
| Semigroup consistency | `DiagnosticPanel.semigroup_error`; `evaluate_diagnostics` |
| Finite-difference generator discrepancy | `DiagnosticPanel.generator_discrepancy`; `evaluate_diagnostics` |
| Energy-law violation | `DiagnosticPanel.evaluate_pair`; `evaluate_diagnostics` |
| Reference-energy error | `DiagnosticPanel.evaluate_pair`; `evaluate_diagnostics` |
| Control-volume balance | `diagnostic_suite.metrics.integral_balance_error` |
| Global drift proxy | `diagnostic_suite.metrics.global_conserved_quantity_drift` |
| Constraint/admissibility components | `diagnostic_suite.metrics.constraint_errors` |
| Perturbation response | `DiagnosticPanel.perturbation_response`; `perturbation_response_error` |
| Scaling commutation | `DiagnosticPanel.scaling_error`; `scaling_law_error` |
| Reference-normalized generator ratio | `add_reference_relative_columns` |
| Benchmark experiment loop | `diagnostic-suite` CLI |
| Analytic PDE validation and generated manuscript table | `diagnostic-suite-referee` CLI; `diagnostic_suite.referee` |
| External benchmark exports (legacy table filenames) | `diagnostic-suite-tables` CLI; `diagnostic_suite.tables` |

The public API is intended for quick post-hoc auditing of user-provided arrays.
The CLI reproduces the manuscript-style benchmark workflow.

Applicability is part of every API report and benchmark CSV. In particular,
benchmark trajectory files without paired perturbations report perturbation
response as unavailable rather than zero. Callable propagators and saved
predictions use the adapters in `diagnostic_suite.propagators`.

The table builder uses horizon two for semigroup/generator comparisons, reports
height-only SW2D without velocity-dependent energy or flux balance, and keeps
CNS3D/MHD3D constraint components in separate columns.

Since version 0.2.0, the package uses scalar advection (`adv2d`) for the APEBench `diff_adv` files.
The previous `ns2d` identity and historical manuscript values are not current
benchmark evidence. The revised manuscript's analytic validation table is
generated by `diagnostic-suite-referee`, separately from external benchmark
exports. The benchmark exporter rejects obsolete schema versions, and does not
select examples merely to fill a requested disagreement table.

All relative state norms flatten channels and spatial axes per sample. Epsilon
is `1e-8`. Energy summaries use spatial means of the configured density. Scaling
normalizes by the transformed right-hand prediction. Control-volume residuals
include cell volumes, face areas, and endpoint-trapezoid time integration; see
the precise normalization in the user guide. Reference generator ratios are
unavailable for a reference scale no larger than epsilon. Per-horizon reports
retain the pair of horizons used for generator discrepancy.

The October revision additionally maps generator/response sensitivity to
 diagnostic-suite-sensitivity, controlled three-equation training to
 diagnostic-suite-controlled, paired analysis to scripts/analyze_controlled_revision.py,
 external coverage/tables to scripts/analyze_external_revision.py, and measured
 costs to scripts/measure_revision_overhead.py. Exact commands and the separation
 between independent verification, controlled training and external application
 are documented in docs/revision_reproduction.md.
